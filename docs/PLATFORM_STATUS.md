# 플랫폼 현황 — 증명 체인 · AI 알파 · 자동 킬스위치 · 해외장 · 채팅 AI

상태 표시: ✅ 구현·테스트 완료 · 🟡 일부 구현 (한계를 적어 둠) · ⛔ 아직 없음 (이유를 적어 둠)
검증: 전체 테스트 통과 · 건너뜀 0개 (개수는 CI 결과 기준 — 문서에 손으로 적지 않음) (PostgreSQL 통합 테스트 포함 — `pytest` 가 임시 DB 를 직접 띄움 · CI 는 `QUANT_NO_SKIP=1`).

## 1. 가장 중요한 질문 — 증명 체인 6단계

이 플랫폼은 "AI 가 똑똑한가" 를 묻지 않는다. 아래 여섯 가지를 **순서대로** 묻는다.
각 단계는 통과 / 미달 / 표본 부족 중 하나로 판정한다. 기준은 `review/net_alpha.py` 에 상수로 고정되어 있고, 결과를 본 뒤에 바꾸지 않는다.

| 단계 | 질문 | 판정 기준 | 실데이터 결과 (휴리스틱 AI, 60거래일) |
|---|---|---|---|
| ① | 데이터가 과거 시점에서 정확했나 | 판단 기록에 저장된 뉴스·공시·마지막 봉이 모두 판단 시각 이전일 것. 수정주가일 것. 유니버스가 시점 기준이거나 전진 기록만 쓸 것 | ✅ 판단 717건 중 누수 0건 |
| ② | AI 확률이 실제 확률과 맞나 | 채점 200건 이상에서 Brier Skill > 0, ECE ≤ 5%p | ❌ Brier Skill −0.056, ECE 10.3% |
| ③ | AI 가 실제로 추가 수익을 만들었나 | AI 장부 − 코어 장부. 60거래일 이상이고 t > 1.64 (단측 5%) | ❌ −1.23%p (t=−0.46) |
| ④ | 비용을 빼도 남나 | AI 알파가 비용 후에도 + 이고, 운용 장부가 비용 후에도 벤치마크를 넘을 것 | ❌ AI 알파 −1.23%p |
| ⑤ | 실제 주문에서도 같은 결과가 나오나 | 실제 장부와 같은 규칙의 시뮬레이션 장부 차이 ±1%p 이내, 실측 슬리피지 ≤ 가정, 체결률 ≥ 90% (KIS 실주문 20건·20거래일 이상) | ⚪ 가상매매만 있어 판정 불가 |
| ⑥ | 그 성과가 반복되나 | 20거래일 구간의 2/3 이상에서 + 이고, 전반과 후반 모두 + | ⚪ 구간 2개 중 1개 (표본 부족) |

이 결과는 LLM 키 없이 휴리스틱 AI 로 돌린 것이다. 판정이 정확히 그렇게 나왔다. 확률은 찍기보다 못했고, AI 는 코어에 수익을 더하지 못했다.
그래서 기본값은 **코어 전용**이다. `.env` 에 넣은 AI 키는 이제 **AI 섀도** 로 매일 판단하고 채점된다. 그 기록이 쌓이면 같은 여섯 단계로 다시 판정한다.

- **AI Alpha 분리 증명 ✅**
  - 같은 날, 같은 가격, 같은 코어 규칙으로 장부 세 개를 굴린다: 코어 / 코어+거부권 / 코어+거부권+위성. 세 장부는 AI 가 관여한 부분만 다르다.
  - 따라서 장부 사이의 차이가 곧 AI 의 순수 기여다. 비용이 포함되어 있고, t 값과 90% 구간을 함께 보여준다.
  - 이 기여는 다시 **거부권·긴급청산**과 **위성 베팅**으로 나눠 보여준다.
- **Point-in-Time 보정·가중치 ✅**
  - 보정기는 적합할 때마다 버전을 기록한다(`calibration_history`).
  - 과거 재생에서는 그 시점 이전에 적합된 보정기와 그 시점에 결과가 나와 있던 성적만 쓴다.
  - 합의 확률 자체도 과거 합의로 한 번 더 보정한다(OOS Ensemble Calibration). 정보가 없는 합의는 0.5 로 눌려 NO TRADE 가 된다.

## 2. 해외장 (미국) 🟡

- **장부**: 미국 대형주 40종목으로 국내와 **같은 코어 팩터 규칙**을 쓴다.
  - 실제 설정 장부 `us-paper` 와 AI 기여 측정 장부 3개(`us-attr-*`)를 둔다.
  - 모두 가상매매이고 단위는 USD다. 벤치마크는 SPY, 수수료는 0.25%(해외주식)이고 매도세는 없다.
- **증명**: 국내와 같은 6단계 체인과 AI 알파 분리 증명을 쓴다. 대시보드에서 🇰🇷/🇺🇸 로 전환한다.
- **데이터**: 무료 일봉을 받는다(Yahoo → 실패하면 Stooq, 수정주가, 키 필요 없음).
  - 과거 백테스트는 **하지 않는다**. 현재 구성 종목으로 과거를 돌리면 생존편향이 생기기 때문이다. 목록을 고정한 날부터의 전진 기록만 성과로 쓴다.
  - ① 단계에는 "전진 기록만 사용" 으로 표시된다.
- **한계**
  - 해외 실주문(KIS 해외주식)은 실계좌로 검증하기 전까지 넣지 않았다. 그래서 ⑤ 단계는 계속 "가상매매만" 이다.
  - 환율 효과는 장부에 반영하지 않는다(USD 기준).

## 3. 자동 킬스위치 — 버튼이 아니라 조건 ✅

![안전 센터](safety_center.png)

5분마다 자동으로 점검하고, 매매 사이클 직전에도 한 번 더 점검한다(`trading/guardian.py`). 조건 하나라도 **심각** 이면 `LIVE TRADING → HALTED` 로 바뀐다.

| 조건 | 심각 기준 |
|---|---|
| Broker disconnect | 증권사 API 연속 3회 실패 |
| Quote stale | 주가가 한도(5영업일)보다 오래됨 · 0/음수 시세 |
| Position mismatch | DB 장부 ≠ 증권사 잔고 2회 연속 |
| Duplicate order | 같은 목표의 미완료 주문 2개 이상 |
| Daily loss limit | 당일 손실이 한도의 1.5배 |
| Abnormal volatility | KOSPI 일간 ±5% (서킷브레이커급) |
| Data source conflict | 증권사 시세 vs DB 종가가 ±30%(가격제한폭) 밖 |
| Model anomaly | champion 확률 붕괴 · 전진 적중률 45% 미만 → **자동 롤백** |
| Risk engine unavailable | 리스크 계산 연속 2회 실패 |
| Database unavailable | DB 응답 없음 |

- **HALTED 상태**: 매도를 포함해 새 주문을 하나도 내지 않는다. 자동 해제는 없다. 원인을 확인한 사람이 안전 센터에서 해제한다. 해제해도 조건이 여전히 심각이면 다음 점검에서 다시 멈춘다.
- **수동 긴급정지**: 기존과 같다. 신규 매수만 막고 매도·위험 축소는 허용한다.

## 4. 연구하고, 검증을 통과한 것만 승격 ✅

```
연구(walk-forward · 비용 2배 · DSR) → Candidate(백테스트 게이트) → Shadow(채점만) → Champion(실매매 모델)
      → 전진 감시(적중률 · Brier · 확률 붕괴) → 이상 시 Rollback(직전 champion 복귀) + 알림 + 기록
```
- AI 는 스스로 바뀌지 않는다. 매일 후보가 생겨도 게이트를 통과해야 shadow 가 되고, 실시간 성적까지 통과해야 champion 이 된다.
- **실험 레지스트리**: 모든 모델 후보와 연구 리포트의 시험 수를 모은다. 시험을 많이 할수록 DSR 기준이 올라간다.
- **AI 켜기 판정**
  - 섀도 60거래일과 채점 200건을 채우고, Brier Skill > 0 이고, 가상 장부 초과수익 +1%p 이상일 때만 "AI 켜기" 를 추천한다.
  - 추천은 알림으로만 간다. 설정은 사람이 바꾼다.

## 7. 사이트 채팅 AI ✅

![채팅 AI](chat_ai.png)

- **위치**: 모든 화면 오른쪽 아래의 **AI 에게 묻기**, 또는 메뉴의 **AI 어시스턴트**. 터미널에서는 `./run.sh chat`.
- **모델**: 설정된 키 중 문맥이 가장 길고 품질이 높은 것을 쓴다. 기본은 Gemini 2.5 Pro이고, 한도에 걸리면 Flash 로 자동 전환한다. `QUANT_CHAT_PROVIDER` 로 바꿀 수 있다.
- **플랫폼 데이터 조회 (읽기 전용 도구 10종)**
  - 종목(국내·해외), 시장, 포트폴리오, 증명 체인
  - 안전 상태, AI 성적, 서버 상태, DB 상태
  - 예: "하이닉스 지금 어때?" → 시세·추세·AI 합의·코어 순위·보유·뉴스·공시. "엔비디아 어때?" → 무료 일봉을 받아 분석(해외는 AI 합의 대상이 아님을 밝힘).
- **안전**: DB 정리 같은 작업은 채팅이 **버튼으로 제안만** 하고, 사람이 눌러야 실행된다. DB 정리는 주문·체결·판단·복기·모델 기록을 절대 지우지 않는다.
- **키가 없거나 한도를 다 썼을 때**: 같은 데이터를 규칙으로 요약해 답한다.
- **검색 개선**: 한글 별명(하이닉스·하닉·삼전·현차·엔솔…), 미국 티커·한글 이름(엔비디아·애플·테슬라…), 종목코드로 찾는다. 해외 종목을 누르면 무료 일봉을 받아 차트를 보여준다.

## 8. 이번 점검에서 찾아 고친 문제

1. **코어 전용이면 AI 를 한 번도 부르지 않았다**
   - 문제: `.env` 에 넣은 AI 키가 쓰이지 않았고, 성적표·보정·저널·근거 추적이 계속 비어 있었다.
   - 수정: 이제 AI 섀도가 새 일봉마다 한 번 판단한다. 실제 주문을 낸 뒤에 판단하므로 LLM 지연이 주문을 늦추지 않는다.
2. **"데이터 없음"**
   - 문제: 뉴스 피드 기본값이 없었고, AI 판단 기록도 없었다.
   - 수정: 기본 국내 경제·증권 RSS 를 넣었다. 대시보드에 **시작 체크리스트와 "지금 채우기"** 버튼을 달았다. `./run.sh` 는 대시보드를 먼저 띄우고 뒤에서 데이터를 채운다.
3. **스케줄러 버그 (예전부터 있던 것)**
   - 문제: `QUANT_MARCAP_DIR` 이 비어 있으면 코어 전략과 함께 **AI 합의 직접매매가 15분마다 같은 장부에서** 돌았다(코어 전용 설정도 무시). 주가 자동 갱신도 꺼져 있었다.
   - 수정: 전략 분기를 고치고, 기본 데이터 위치를 쓰게 했다. 회귀 테스트를 추가했다.
4. **모델 파일이 없어지면 AI 판단 전체가 멈췄다**
   - 수정: 그 모델만 빼고 계속 판단하고, 알림을 보낸다.
5. **미국 고가 종목** 은 1주도 못 사는 경우가 있었다.
   - 수정: 국내와 같은 "다음 순위 대체" 규칙을 적용했다.
6. **대시보드 속도**
   - 문제: 전 종목 일봉을 매번 다시 읽었다.
   - 수정: 60초 캐시를 넣었다(적재 시 무효화). 두 번째 호출부터 0.03~0.4초.

  - 수정: 공급사를 동시에 부르고, 종목마다 즉시 저장하고, 진행률(예: 12/42)을 표시한다.
  - 응답 없는 공급사는 3번 연속 실패하면 10분간 건너뛴다(서킷 브레이커).
  - 백그라운드 채우기와 스케줄러가 같은 판단을 두 번 하지 않게 잠갔다. SQLite 는 WAL 모드와 30초 대기로 동시 사용 충돌을 막았다.
- **SK하이닉스처럼 코어 후보가 아닌 종목은 AI 판단이 영영 없었다**
  - 종목 화면을 열면 AI 가 **그 자리에서 판단**한다(키가 있으면 자동, 없으면 버튼).
  - 본 종목과 채팅에서 물어본 종목은 **관심 종목**이 되어 매일 판단한다(최근 20개).
- **엔비디아 시세: Yahoo 429 · Stooq 결과 없음**
  - 수정: yfinance(브라우저 흉내) 일괄 받기 → Yahoo query1·query2 → Nasdaq → Stooq 순서로 시도한다.
  - 실패한 종목은 30분 동안 다시 요청하지 않아 차단이 길어지지 않는다.
- **설치 때 `Ignoring invalid distribution ~ip` 경고**
  - 원인: 중단된 pip 업그레이드가 깨진 폴더를 남겼다.
  - 수정: `./run.sh` 가 명령마다 자동으로 정리한다.
- **`No module named pip` 로 설치가 멈춤**
  - 원인: 예전 폴더에서 복사해 온 가상환경(.venv)이 깨져 있었다.
  - 수정: `./run.sh` 가 pip 를 자동 복구하고, 다른 폴더에서 복사된 .venv 는 알아서 새로 만든다.
- **`No space left on device`**
  - 원인: 버전마다 새 폴더에 가상환경(약 700MB)과 주가 데이터를 새로 설치해, 폴더 10개면 수 GB 가 쌓였다.
  - 수정: 이제 `~/.quant-ai` 에 한 번만 설치해 공용으로 쓴다. 새 폴더는 직전 버전의 `.env`·DB 를 자동으로 가져온다. `./run.sh clean-old` 로 옛 설치 파일과 pip 캐시를 확인 후 정리한다.
- **`.git/index.lock: File exists`**: 중간에 끊긴 데이터 받기의 잠금 파일과 망가진 저장소를 자동으로 복구한다.
- **상단 "작업 실패 N건"**: 누르면 서버·DB 화면으로 가고, 마우스를 올리면 실패한 작업 이름과 오류가 보인다.

### 종목 화면 — 투자 전에 보는 것들 (v10)

엔비디아·삼성전자 같은 종목을 열면 맨 위에 **다가오는 일정**이 D-day 로 뜬다.

- **다가오는 일정**
  - 실적 발표일: 장 시작 전/장 마감 후 구분, EPS·매출 예상치. 날짜가 확정이 아니면 "예상" 표시.
  - 배당락일, 배당 지급일.
  - 국내 종목: DART 공시(기업설명회·주총·배당·잠정실적).
  - 국내에서 발표일을 모르면 **분기보고서 법정 제출 기한**(분기 45일·사업보고서 90일)을 "예상"으로 보여준다.
  - 실적 발표가 7일 안이면 변동성 경고가 뜬다.
- **투자 전 체크**: 시가총액, PER, 선행 PER, PBR, EPS, 배당수익률, 베타, 평균 거래량, 외국인 소진율(국내), 52주 범위 안에서 현재 위치.
- **애널리스트 전망**
  - 평균·최고·최저 목표가와 현재가 대비 여력, 투자의견 분포.
  - 국내는 최근 증권사 리포트 제목도 보여준다.
  - 플랫폼 AI 판단과는 별개라고 표시한다.
- **실적**: 분기 매출·영업이익 막대, EPS 예상 대비 실제(상회/하회)와 서프라이즈 %.
- **재무 건전성**: 성장률, 이익률, ROE, 부채비율, 잉여현금흐름, 기관 보유, 공매도 비율.
- **기업 정보**: 섹터, 산업, 직원 수, 웹사이트, 사업 설명. "AI 한국어 요약" 버튼이 있다.
- **관련 뉴스**: 국내 RSS 에서 종목명·별칭(엔비디아·엔비·NVDA 등)이 제목에 들어간 기사와 Yahoo 뉴스를 합쳐, 원문 링크와 함께 보여준다.
- **출처**: 모두 키가 필요 없는 무료 공개 자료다.
  - 해외: Yahoo Finance, 막히면 Nasdaq 공개 API.
  - 국내: 네이버 증권, Yahoo(.KS/.KQ), DART.
- **캐시와 재시도**
  - 결과는 6시간 캐시하고, 실패한 소스는 30분 쉬었다가 다시 시도한다.
  - 모두 실패하면 이전 결과를 "이전 자료"로 표시한다.
  - D-day 는 볼 때마다 다시 계산한다.
- **채팅 AI**: "엔비디아 어때?" 라고 물으면 다가오는 일정(D-day)을 맨 앞 근거로 말한다. 목표가와 지표도 함께 쓴다.

**홈에서 고친 것**
- **오늘의 주요 뉴스가 비어 있던 문제**
  - 원인: 화면을 연 뒤에 뉴스가 수집됐는데, 화면이 그 사실을 몰랐다.
  - 수정: 체크리스트에서 뉴스·판단이 채워지면 바로 다시 그린다.
  - "피드 미설정"이라는 잘못된 문구도 "수집 대기"로 바꿨다.
- **AI 종합 분석 칸에 해외 종목이 남던 문제**: 해외 종목을 보고 왔으면 AI 합의가 있는 국내 종목으로 대신 보여준다.
- **관심 종목이 가나다순이던 문제**
  - 이제 보유 → 코어 → 내가 본 종목 → AI 신호 → 거래대금 큰 순으로 정렬한다.
  - 각 종목에 보유·코어·관심 표시가 붙는다.
- **국내 지수 탭이 아무 종목으로 채워지던 문제**
  - KOSDAQ 시총가중 대용 지수를 추가했다. 벤치마크는 그대로 KOSPI 다.
  - 빈칸은 거래대금 상위 "대표 종목"으로 채운다.
- **주요 경제 이벤트**: 열어 본 종목의 30일 안 실적 발표·배당락이 D-day 와 함께 여기에 모인다.

## 8-2. 컴퓨터만 켜 두면 — 24시간 관찰 · 기록 · 복기 · 검증된 것만 실제 돈 (v11)

![24H 관제실](control_room.png)

**24H 관제실** (메뉴 두 번째)은 흐름을 한 화면에 보여준다.

- **흐름**: 수집 → 정리 → 독립 분석 → 최종 판단 → 예측 저장 → 실제 결과 비교 → 성적 누적 → 승격.
  - 단계마다 마지막 실행 시각과 상태가 표시된다.
- **방금 저장된 예측**: 종목, 현재가, 요인(뉴스·추세·시장·거래량·해외 연동 `+++`/`−−`), AI 예상, 실제 결과를 카드로 보여준다.
  - AI 예상 형식: "5거래일 상승 확률 68% · 예상 +1.8%".
  - 채점되면 적중 ✔ / 빗나감 ✘ 가 붙는다.
- **24시간 작업표**: 작업마다 주기, 마지막 실행, 다음 실행, 상태.

### 예측 성적표 — "10개 중 3개"가 아니라 돈으로
최근 100회(종목·날짜별 마지막 판단 하나씩)를 다음 기준으로 본다.
- 방향 적중률
- 평균 기대수익과 평균 실제수익
- 비용 차감 후 신호 수익
- MDD: 신호를 매일 1/기간씩 나눠 따른 겹침 포트폴리오 기준
- 확률 보정: Brier Skill, ECE, 보정 곡선
- 국면별 적중률

틀린 예측에는 이유(충돌 중 소수 의견이 맞음 / 과신 / 이벤트 쇼크 등)가 자동으로 붙는다.

기대수익은 AI 가 따로 말한 숫자가 아니다. 합의 확률과 최근 변동성에서 계산한다: `σ·√h·Φ⁻¹(p)`. 화면에도 그렇게 적었다.

미국 예측도 이제 채점된다. 전에는 저장만 되고 채점되지 않던 문제를 고쳤다.

### 검증 사다리 — 자동 승인 · 자동 강등
단계는 `과거 검증 → Shadow → Paper → 소액 Live(20만원) → Live 확대` 이고, 한 번에 한 칸씩만 올라간다.

- **소액 Live 조건**: 아래 7개를 모두 통과해야 한다. 기준은 미리 고정했다.
  - ① 예측 300회 이상
  - ② 방향 적중률 55% 초과
  - ③ 비용 차감 후 수익 > 0
  - ④ 확률 보정: BSS > 0, ECE ≤ 5%
  - ⑤ 최대 손실 제한
  - ⑥ 최근 30일에도 성능 유지
  - ⑦ 국면 2개 이상에서 각 50% 이상
- **실제 돈의 추가 조건**: `.env` 에 사람이 미리 동의해 둔 경우에만 쓴다 (`QUANT_LIVE_ENABLED` + 확인 문구). 동의가 없으면 "준비됨" 알림만 보낸다.
- **강등**: 아래 중 하나면 즉시 Shadow 로 내려가고, 14일 동안 재승격하지 않는다.
  - 최근 50회 적중률 50% 미만
  - 최근 30일 수익 < 0
  - 보정 붕괴
  - 실전 낙폭 −10% 초과
  - HALTED
- **Live 확대**: 자동으로 하지 않는다. 금액은 사람이 정한다.
- **실제 돈 계좌의 AI**: 설정과 무관하게 사다리 '소액 Live' 이상일 때만 쓴다 (안전장치).
- **LLM 과거 검증을 하지 않는 이유**: LLM 은 학습 데이터에 미래가 섞여 있어 과거로 공정하게 시험할 수 없다. 그래서 과거 검증은 퀀트 모델만 하고, LLM 은 Shadow 부터 시작한다.

### 실시간 알림 (토스트 · 알림센터 · 데스크톱 · 소리)
![토스트 알림](toasts.png)

- **급등·급락**: 장중 2.5분마다 확인한다. 대상은 보유·관심·코어 종목이다.
  - 전일 대비 ±3/5/10% 돌파.
  - 20분 안 ±2% 급변.
  - 시세 출처: 국내는 네이버, 미국은 Yahoo 실시간(지연 가능). 표시·알림 전용이고 매매는 증권사 시세만 쓴다.
- **그 밖의 알림**: 새 AI 신호(방향이 바뀐 BUY/SELL), 새 공시, 중요 뉴스, 이벤트 재분석, 예측 채점 결과, 실적 발표 D-1·당일, 자동 정지/해제, 승격·강등, 시장 RISK ON/OFF 전환, 작업 연속 실패.
- **화면**
  - 오른쪽 위에 토스트가 뜬다. 누르면 해당 화면으로 가고, 마우스를 올리면 멈춘다.
  - 종 아이콘에 안 읽은 개수가 표시되고, 누르면 알림센터가 열린다.
  - 설정에서 종류별로 켜고 끌 수 있다. 창이 가려져 있을 때의 데스크톱 알림과 알림음도 여기서 켠다.
- **외부 알림(텔레그램 등)**: 보유 종목 ±5%, 자동 정지, 강등만 보낸다.
- **실시간 가격**: 화면 위 LIVE 티커와 관심 종목·종목 화면의 가격이 오르면 빨강, 내리면 파랑으로 깜빡인다.

### 추천 1~8

1. **종목별 알림 규칙**: 목표가 · 손절가 · 등락률 · 거래량 N배.
   - 한 번 울리면 꺼지거나, 매일 반복하도록 고를 수 있다.
   - 종목 화면에서 바로 추가할 수 있다 (+10% · −7% · ±5% · 거래량 3배 빠른 버튼).
2. **아침 브리핑**: 오늘 일정, 밤사이 미국, 어제 채점, 관심 종목 AI 예상, 매크로·뉴스·업종 요약.
3. **앱 설치 + 웹 푸시**
   - VAPID 서명과 RFC 8291 암호화를 직접 구현했다. 외부 서비스 가입은 필요 없다.
   - 휴대폰에서 받으려면 HTTPS 로 열어야 한다 (docs/MOBILE.md).
4. **KIS 실시간 체결 (웹소켓)**
   - 장중에만 연결하고, 최대 40종목을 본다. 3초마다 알림을 판단한다. 끊기면 다시 붙는다.
   - 표시·알림 전용이고 주문에는 쓰지 않는다.
5. **LLM 묶음 호출**
   - 기본 3종목을 한 요청에 묻는다. 분당 토큰이 작은 Groq 는 1(끔)이다.
   - 빠진 종목은 하나씩 다시 묻고, 묶음이 실패하면 전부 하나씩 다시 묻는다.
6. **공시 원문 AI 요약**: DART 원문에서 금액·비율·기간·상대를 뽑는다. LLM 이 없으면 숫자가 들어간 줄로 요약한다.
7. **외국인·기관 수급**: 5·20일 순매수, 연속 일수, 보유율. 체크리스트의 수급 항목이 실제 수급으로 바뀌었다.
8. **DB 자동 백업**: 하루 1개, 7개 보관, gzip 압축, 무결성 확인.

### 새 화면
- **검증실 · 예측 장부**: 독립 평가, 장부 무결성, 누수 감사, Brier 분해, 오차 분해, 드리프트, 모델 계보, 프롬프트 버전.

- **종목 화면에 추가된 것**: 알림 설정, 수급, 연관 종목, 공시 요약.

- **CSP 때문에 인라인 `onclick` 버튼이 동작하지 않던 문제**
  - 해당 버튼: 종목 화면 "AI 에게 묻기", "AI 한국어 요약", 홈 이벤트 클릭 등.
  - 원인: 브라우저 보안 정책(CSP)이 인라인 스크립트를 막았다.

### 실제 시장 예측력 — 증거 세 층

![실제 예측력](power.png)

- **A. 사후 검증** (실제 KRX 2010~2026, 상장폐지 포함, 시점 기준 시총 상위 100): 코어 점수의 20일 순위 예측력
  - 개발 구간(2011~2020) IC **+0.002 (t=0.09)** — 우연과 구분되지 않음
  - 검증 구간(2021~2026-07) IC **+0.070 (t=2.56)** — 유의. 무작위 대조군 −0.019
  - 비용 후 상위 20 초과수익 +0.26%/20일 (**t=0.63**) — 유의하지 않음
  - 판정: **"혼재"** — 순위 예측력은 일부 구간에서만 보이고, 비용 후 돈으로는 아직 증명되지 않았다
- **B. 사전 등록**: 성공 기준(적중률 ≥ 기준선 + 4%p, α=0.05, β=0.2)을 결과를 보기 전에 해시로 봉인
- **C. 전진 검증**: 등록 이후 봉인된 예측만으로 SPRT. 매일 봐도 거짓 양성이 α 로 유지된다. **이것만이 실제 돈의 근거**

- **Fail-closed**: 매매 준비 기록이 없거나 2시간 넘었거나 다른 장부 기준이면 주문 직전에 다시 점검한다. 점검 자체가 실패해도 신규 매수를 막는다. Truth Center 가 실패하면 DATA 관문이 빨강이다.

### 직접 써 보고 찾아 고친 문제

- **AI 성능 저하 감지가 거의 항상 '관찰' 경보** — 하루에 종목 100여 개를 판단하면 같은 날 판단들은 시장 방향을 함께 탄다 (나쁜 하루 = 100건 동시 오답). 기존 검정은 이를 독립 표본으로 봐서, 모의실험에서 **안정적인 AI 도 100% 경보**가 났다. 하루 여러 건이면 **일별 적중률**로 묶고 표준편차도 일별 값에서 추정하도록 바꿨다 → 안정인데 '저하' 1% 이하, 58%→45% 하락 검출 98% 이상 (모의실험 300회). 창도 '최근 1000건'(하루 100건이면 10일)에서 '최근 250일'로.
- **실데이터 결과**: 시장 국면 AI 가 초기 53% → 최근 20거래일 44% (일별 z=−2.8) 로 **성능 저하** 판정 · 알림. 뉴스·경제 AI 는 '관찰'.
- **이벤트 D-day 가 하루 어긋남** — 캘린더에 저장된 D-day 는 만든 날 기준이라, 자정이 지나면 최대 26시간 동안 "실적 D-1 매수 ×0.5" 와 매매 준비 EVENT 관문(오늘 FOMC 등)이 하루 늦게 걸렸다 → 주문·점검하는 날 기준으로 다시 계산 (회귀 테스트 추가).
- **DART 공시에서 이벤트를 못 뽑음** — 실제 보고서명은 "자기주식취득결정" 처럼 띄어쓰기가 없는데, 추출기는 "자기주식 취득" 만 찾았다 → 공백 무시 비교.
- **별표 관심종목이 홈 관심 종목 목록에 반영되지 않음** (v14) → 맨 앞 + ★ 탭.
- **AI Health 숫자가 판정과 모순** — '적중'이 최근 400건(약 4일), '최근 60'이 60건(하루도 안 됨)이었다 → 전체 · 초기 · 최근 20거래일(판정과 같은 숫자)로.
- **Risk AI 를 '판단 멈춤'으로 오탐** — Risk AI 는 경고를 낸 날만 기록한다 → 제외하고, 'AI 전체가 멈춤'과 '한 AI 만 멈춤'을 구분.
- **사전 게이트에서 같은 차단 사유가 두 번** 표시 → 정리.
- **외부 자료(프로필)가 늦으면 알림 규칙·관계·공시 카드까지 늦게 뜸** → 기록으로 먼저 표시.

### 키 문제 ("DART·FRED 를 .env 에 넣었는데 '키 없음'") — 진짜 원인

`.env` 읽기 문제가 아니었다. **`./run.sh` 가 이미 떠 있는 옛 버전 서버를 그대로 재사용**했다.
그래서 화면은 옛 폴더의 코드와 옛 폴더의 `.env` 를 보고 있었다. 예를 들어 v16 폴더에서 띄운 서버가 8050 포트를 잡고 있으면, v17 폴더에서 `./run.sh` 를 실행해도 v16 서버가 그대로 남는다.

- `/api/health` 가 (내 PC 에서 부를 때만) 서버의 **버전·폴더·.env 위치·PID** 를 알려 준다.
- `./run.sh` 는 떠 있는 서버가 **이 폴더의 서버인지** 확인한다. 아니면 그 서버를 끄고 새로 띄운다. 끌 때는 PID 로, 그리고 quant_ai 프로세스인지 확인한 뒤에만 끈다.
- 다른 프로그램이 포트를 쓰고 있으면 끄지 않고 다른 포트를 안내한다.
- `./run.sh stop` 이 새로 생겼다.
- 설정 화면 맨 위 배너에 **"서버 v0.18.0 · 폴더 … · .env …"** 가 보인다. 이 줄의 폴더가 지금 쓰는 폴더와 다르면 옛 서버다.

## 8-11. V20 — "500만원 → 1억" 을 위한 정직한 기반 (P0 → P3 순서)

목표를 숫자로 따져 보면 이렇다. 500만원이 1억이 되려면 20배여야 한다. 적립 없이 10년 안에 하려면 해마다 35% 가 필요한데, 세계 최고 펀드도 오래 유지하기 어려운 수익률이다.
그래서 이번 작업은 **"확률을 보여 주고, 확률을 올리는 행동(적립·기간·비용)을 자동으로"** 하는 것과 **"AI 가 진짜 실력이 있는지 시장 대비로 증명"** 하는 데 집중했다.

## 9. 솔직한 한계

- **v20 목표 계획의 숫자는 가정이다.** 과거 16년의 평균 수익과 흔들림으로 3,000가지 미래를 만든 것이다. 앞으로 시장이 과거와 다르면 확률도 달라진다. 세금·수수료는 연 수익 가정에 대략 포함했다.
- **Quant v2 의 연구 결과는 비용 전이다.** 비용·체결을 반영한 백테스트 관문을 통과해야만 Shadow → champion 으로 쓰인다. 통과하지 못하면 '학습된 모델 없음' 이 계속 나온다. 이것은 의도된 동작이다.
- **전략 기대치는 그대로다.** 코어는 16년 실데이터에서 KOSPI 와 비슷한 수익에 변동성이 더 작다. 이번 작업은 "AI 가 돈을 더 버는지" 를 **증명할 수 있게** 만든 것이지, 수익을 올린 것이 아니다.
- **AI 의 가치는 아직 증명되지 않았다.** 휴리스틱 AI 는 ②③④ 에서 미달이다. 무료 LLM 키로 수 개월 쌓인 기록이 같은 기준을 통과해야 AI 를 켠다.
- **⑤ 실주문 동일성**: KIS 모의·실전 주문 기록이 20건·20거래일 이상 쌓여야 판정된다.
- **1년 안의 수익은 시스템이 보장할 수 없다.** 사다리는 기술 검증을 1년보다 훨씬 빨리 끝낼 수 있게 해 주지만, 투자 우위가 계속되는지는 실측으로만 알 수 있다.
- **실시간 시세·커뮤니티 수집은 공개 페이지 기반**이라 사이트 구조가 바뀌면 멈출 수 있다. 실패하면 조용히 쉬었다가 다시 시도하고, 매매에는 쓰지 않는다.
- **종목 상세의 외부 자료**(일정·지표·목표가)는 무료 공개 소스라 가끔 막히거나 늦을 수 있다. 화면에 출처와 기준 시각을 항상 표시한다.
- **새 외부 연결은 이 환경에서 실제 서버로 시험하지 못했다.**
  - 대상: 네이버 수급·토론방·실시간, StockTwits, DART 원문, KIS 웹소켓, 웹 푸시.
  - 응답 모양을 맞춘 가짜 데이터와 로컬 테스트 서버로만 확인했다. KIS 웹소켓은 로컬 웹소켓 서버, 웹 푸시는 암호화 왕복·서명 검증으로 시험했다.
  - 형식이 다르면 각 기능은 조용히 쉬고 다시 시도하며, 매매에는 영향을 주지 않는다.
- **업종 분류**: 국내는 WICS 를 먼저 쓴다. WICS 를 받지 못하면 Yahoo 업종을 옮긴 것으로 돌아간다.
- **v13 새 외부 연결도 실제 서버로 시험하지 못했다.**
  - 대상: WICS · OpenTimestamps · GitHub Gist · Yahoo 옵션·실적 이력 · 위키 조회수 · 네이버 데이터랩 · FRED 발표 일정 · KIS 검증 스위트·호가 스트림.
  - 이 환경의 네트워크가 막혀 있어 응답 모양을 맞춘 가짜 데이터로만 확인했다.
  - 실패하면 기록하고 다음에 다시 시도하며, 매매 판단에는 영향이 없다.
- **실제 시장 예측력은 아직 증명되지 않았다.** 사후 검증은 "혼재" 이고, 전진 검증은 이제 시작이다. 실제 돈은 소액 한도 안에서만.
- **무료로 안정적으로 구할 수 없어 넣지 않은 것**: 해외 PIT 유니버스, 국내 종목별 옵션, 국내 실적 컨센서스.
- **v14 의 2차 가격 소스(Yahoo)도 이 환경에서 실제 서버로 시험하지 못했다.** 정렬·채우기·덮어쓰기는 가짜 데이터로 검증했다.
- **Truth Center 는 "사실인가" 를 확인할 뿐, 초과수익의 증거가 아니다.** 🔴 없음 = 매매해도 된다는 뜻이 아니라, 매매를 막을 사실 문제가 없다는 뜻이다.
- **v15 의 사전 리스크 게이트는 '지금 가격'이 아니라 마지막 일봉 종가 기준이다.** 장중 실시간 가격은 실제 매매 사이클에서만 반영된다.
- **뉴스·공시 요약은 규칙 기반**이다 (LLM 요약은 공시 원문 요약에만 쓴다). 이 환경은 네트워크가 막혀 실데이터 DB 에 뉴스·공시가 없어 "없음" 으로 보인다 — 테스트 데이터로 검증했다.
- **v16 의 데이터 출처·지연 추적은 '우리가 받은 시각'까지다.** 제공자가 원래 늦게 준 데이터(무료 소스의 15~20분 지연 등)는 제공자 시각을 알 수 있을 때만 표시된다.
- **뉴스 '예상 영향'은 과거 평균**이다 (같은 톤 뉴스 다음 날 시장 대비 움직임). 인과가 아니며 표본이 8건 미만이면 표시하지 않는다.
- **실패 연구의 태그는 원인 '후보'**다 — 같은 기간에 있었다는 뜻이지 원인이라는 증거가 아니다.
- **KIS 모의계좌·WebSocket·실측 슬리피지·장기 전진 기록은 키와 시간이 필요**해서 이번에도 검증되지 않았다 (`#validation` 진행률 0%). 코드가 아니라 실제 계좌와 시간이 병목이다.
- **규제·라이선스·보안 화면은 법률 자문이 아니다.** 다른 사람에게 제공하려면 변호사 검토가 먼저다.
- **V17 미국 주식은 여전히 자동 매매가 안 된다.** 주문표를 보고 사람이 직접 넣는다. KIS 해외 주문 API 는 모의 서버로 검증하기 전에는 열지 않는다.
- **V17 세금 계산은 추정**이다. 해외주식 양도소득세 22%(지방세 포함)·연 250만원 기본공제를 가정했고, 손실 상계·환율 기준일(취득·양도일 기준환율) 등 세부는 단순화했다. 신고 전에 세법·증권사 자료로 확인한다.
- **V17 뉴스 구조화는 LLM 키가 있어야 '이벤트·확신도·요약' 이 채워진다.** 키가 없으면 키워드+부정어 규칙이다 — 반어·비교·조건문("~라면")은 여전히 틀릴 수 있다.
- **V17 이벤트 전략(PEAD)은 무료 실적 데이터(네이버 컨센서스·Yahoo)** 라 발표가 늦게 잡히거나 빠질 수 있다. 전진 30건이 쌓이려면 실적 시즌 1~2번이 필요하다.
- **V17 VI 판단은 일봉 근사**다 (실제 VI 발동 기록은 KIS 실시간으로만 정확).
- **유료 API 는 넣지 않았다.** 실적 일정·컨센서스를 안정적으로 받으려면 유료(예: FnGuide/에프앤가이드, 해외는 유료 실적 캘린더)가 필요하다 — 개인 사용 비용 대비 효과를 먼저 전진 기록으로 확인하는 것을 권한다.
- **전략 성과 자체는 이번에도 바뀌지 않았다.** 이번 작업은 '덜 잃게' 와 '확인하기 쉽게' 이지 수익을 올린 것이 아니다.
- **과거 재생(투자 한도)은 지수로 근사**한다 — 코어 전략 자체의 자산곡선이 저장돼 있지 않으면 시총가중 대용 지수의 하루 변동으로 센다. 이 환경의 실데이터(2023~2026)는 하루 −5% 이상이 잦아 한도를 넓혀도 자동 정지가 연 몇 회 남는다 (그런 날은 실제로 멈추는 게 맞을 수도 있다).
- **SEC EDGAR 는 연락처가 담긴 User-Agent 가 필요**하다 (`QUANT_SEC_USER_AGENT`). 이 환경에서는 네트워크가 막혀 가짜 응답으로만 확인했다.

- **V18 로고는 인터넷에서 받아 온다.** 이 환경은 네트워크가 막혀 있어 이니셜 아이콘으로만 확인했다. 받기 실패한 종목은 7일 동안 다시 시도하지 않는다. 로고는 각 회사의 상표이므로 식별 표시로만 쓴다.
- **V18 기간별 확률(1/5/20일)은 '과거에 비슷한 확률을 냈을 때 실제로 오른 비율'**이다. 예측 장부에 결과가 30건 이상 쌓여야 보인다. 모델 자체가 기간별로 따로 예측하는 것은 아니다.
- **V18 중요도 🔴🟠🟡⚪ 와 영향 종목은 규칙 점수**다 (기사 중요도·톤·이벤트 종류·출처 신뢰도·보유 여부). 🟠🟡 종목은 같은 업종·자주 함께 언급된 종목일 뿐, 실제로 영향을 받는다는 증거는 아니다.

- **V19 쉬운 성적표의 '지수 대비'는 같은 기간 지수(국내: 시총가중 대용 지수, 미국: SPY)와의 비교**이고 비용은 수수료·미끄러짐·세금 가정값이다 (실측 슬리피지가 쌓이면 그걸 쓰는 게 맞다).
