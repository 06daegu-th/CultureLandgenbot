# 규제 설계 — 기능이 어느 단계인가

> ⚠️ **법률 자문이 아닙니다.** 다른 사람에게 제공하기 전에 금융규제 전문 변호사와 검토하세요.
> (투자자문·일임업 인가, 유사투자자문업 신고, 마이데이터, 개인정보, 데이터 이용계약)

지금 구성은 **본인이 본인 계좌에 쓰는 개인용**입니다 (`QUANT_SERVICE_LEVEL=personal`). 서비스 단계를 바꿀 때 무엇을 켜고 끌지 보이도록,
기능마다 단계를 코드(`src/quant_ai/governance.py`)에 표시했고 화면 `#governance` 에서 확인할 수 있습니다.

| 단계 | 뜻 | 이 시스템의 기능 | 검토할 것 |
|---|---|---|---|
| 1. INFORMATION | 시세·뉴스·공시·일정·재무를 보여줌 (판단 없음) | 시세·차트·일정·뉴스·공시 · 데이터 출처·신뢰도 | 출처 표기 · 데이터 이용계약 |
| 2. ANALYSIS | 지표·위험·AI 확률을 누구에게나 같게 | AI 확률·판단 이유·성적표·예측 장부 · 비교·실적·수급·위험 지표 | 불특정 다수 대상 → 유사투자자문업 신고 여부 |
| 3. PERSONALIZED ANALYSIS | 내 보유·성향·한도에 맞춘 분석 | 내 보유 위험·Portfolio OS·오늘 할 일 · 성향 맞춤 목록 · 투자 논리·저널 실수 · 사전 리스크 게이트 | 개인정보·마이데이터 · 자문업 해당 여부 |
| 4. INVESTMENT ADVICE | 특정인에게 "이 종목을 사라/팔아라" | AI BUY/SELL 을 '행동'으로 권유하는 표현 | **투자자문업 인가 대상일 수 있음 — 검토 전 제공 금지** |
| 5. ORDER | 판단을 증권사 주문으로 실행 | 가상/섀도 자동매매 · KIS 모의·실전 자동 주문 | **투자일임업·주문 대리** — 인가·내부통제·보안 요건 |

## 지금 지키는 원칙

- 화면의 모든 AI 판단 옆에 "정보 제공 목적 · 투자 권유 아님 · 성과 보장 없음"을 표시한다.
- '성향에 맞는 종목'은 **추천이 아니라 조건에 맞는 목록**으로 표시한다.
- AI 는 주문 권한이 없다 (신호 → 합의 → 리스크 게이트 → 실행 엔진). 실전 주문은 여러 안전장치(환경변수 2개·소액 상한·검증된 챔피언)를 통과해야만 켜진다.
- 수동 모의 주문은 **실제 돈이 아닌 별도 장부**에만 기록된다.
- 좋은 숫자만 보여주지 않는다: 공개 AI 성적표는 최근 1000건 전부 · 실패 사례 포함.
