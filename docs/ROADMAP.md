# 다음 단계 — 지금 할 일과 앞으로의 개선 순서

## A. 지금 사용자가 할 일 (키를 넣은 뒤 10분)

1. `./run.sh doctor --ai --kis --notify`
   - AI 역할별로 짧은 요청을 한 번씩 보내 키·모델·네트워크를 확인한다. 한도는 1회씩 쓴다.
   - ❌ 가 있으면 그 줄의 안내대로 고친다. 키는 채팅에 붙여넣지 말고 `.env` 에만 넣는다.
2. `./run.sh`
   - 대시보드가 뜨면 홈의 **시작 체크리스트**를 확인한다. 비어 있는 항목은 **지금 채우기**로 채운다.
3. 오른쪽 아래 **AI 에게 묻기**에서 "서버 상태 알려줘", "하이닉스 어때?", "엔비디아 어때?" 를 물어본다.
   - 채팅 창 위쪽에 모델 이름(예: gemini-flash-latest)이 보이면 연결된 것이다.
4. KIS 모의투자 키가 있다면 장중에 `./run.sh kis-check` 로 실제 주문 경로를 한 번 확인한다.
   - 이 기록이 쌓여야 증명 체인 ⑤(실주문 동일성)가 판정된다.
5. 3개월 동안은 **코어 전용을 유지**한다.
   - AI 는 매일 섀도로 채점되고, 증명 체인과 **AI 켜기 판정**이 스스로 쌓인다.
   - 판정이 "추천" 으로 바뀌면 알림이 온다. 그때 `QUANT_CORE_ONLY=false` 를 검토한다. 먼저 `QUANT_AI_OVERLAY=veto` 부터 켠다.

## B. 앞으로의 개선 (효과 큰 순서)

| 순위 | 항목 | 왜 | 조건 |
|---|---|---|---|
| 1 | LLM 호출 묶음 처리 (여러 종목을 한 요청에) | 무료 한도 안에서 판단 종목 수를 3~5배로 늘릴 수 있다 | 공급자별 응답 품질 비교 후 |
| 2 | 실측 슬리피지 → 백테스트 비용 자동 반영 | ④가 가정이 아니라 실측 비용으로 판정된다 | KIS 실주문 50건 이상 쌓인 뒤 |
| 3 | KRX 휴장일 자동 수집 | 지금은 `artifacts/holidays.json` 을 수동으로 넣는다 | 공공데이터 API 키 |
| 4 | KIS 웹소켓 실시간 시세 | 장중 급변 감지(킬스위치 ⑥)가 1시간 단위에서 초 단위로 빨라진다 | 모의계좌에서 검증 |
| 5 | 해외 실주문 (KIS 해외주식) | 미국 증명 체인 ⑤ 판정 | 실계좌로 소액 검증 뒤에만 |
| 6 | 원화 환산 성과 (환율 효과 분리) | 미국 장부의 실제 원화 수익 | FRED 원/달러 사용 |
| 7 | 모바일 푸시 (PWA) · 일일 요약 리포트 | 알림 채널 없이도 HALTED 등을 즉시 알 수 있다 | — |
| 8 | 대시보드 외부 접속 시 HTTPS 역프록시 가이드 | 지금은 127.0.0.1 전용이고, 외부 접속은 토큰 필수 | — |
| 9 | 백업 자동화 (`quant_ai.db` 일일 사본) | SQLite 파일 손상 대비 | — |
| 10 | 다계좌 · 세금·배당 추적 | 개인 투자자 편의 | — |

## C. 하지 않기로 한 것 (이유)

- **AI 가 스스로 학습해서 곧바로 실매매 모델을 바꾸는 기능.** 검증 게이트와 롤백이 있는 승격 체계만 쓴다.
- **미국 과거 백테스트.** 무료로는 상장폐지 종목이 포함된 과거 유니버스를 구할 수 없다. 생존편향으로 성과가 부풀려지므로 하지 않는다.
- **수익을 약속하는 화면이나 문구.** 모든 판정은 표본이 부족하면 "표본 부족" 으로 표시한다.
