# 데이터 라이선스 — 개인 사용 vs 상용 서비스

> 참고용 정리입니다. 각 제공자의 **최신 약관·계약서가 우선**이며 법률 검토가 필요합니다.
> 화면 `#governance` 에도 같은 표가 있고, `QUANT_SERVICE_LEVEL` 이 personal 이 아니면 상용 불가 소스 경고가 뜹니다.

| 출처 | 쓰는 곳 | 개인 사용 | 상용 서비스 | 위험 |
|---|---|---|---|---|
| FinanceData/marcap (KRX 일별 시세) | 국내 일봉·시총 (코어·백테스트) | 가능 | 원천이 KRX — **KRX 데이터 상품 계약 필요** | 높음 |

| 네이버 금융 (공개 페이지) | 실시간 폴링·수급·컨센서스·토론방 | 개인 조회 | 크롤링 기반 — **상용 불가로 봐야 함** | 높음 |

## 상용화 경로

개발용(무료) 데이터 → **상용 데이터 계약** (KRX 정보데이터시스템·시세 벤더) → 라이선스 범위 확인 (사용자 수·재배포·표시 지연) → 사용자 수 증가 → 비용 관리

코드는 이미 **1차/2차 소스 분리**(`data/sources.py`)와 출처·수집 시각 기록(`collected_at`)이 되어 있어, 벤더를 바꿀 때 수집기만 교체하면 됩니다.
