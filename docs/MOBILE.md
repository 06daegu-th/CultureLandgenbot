# 휴대폰으로 보기 · 알림 받기

알림을 휴대폰에서 받는 방법은 세 가지입니다. 쉬운 순서입니다.

## 1. 텔레그램 (가장 쉬움 · 추천)

사이트를 열어 두지 않아도 알림이 휴대폰으로 옵니다.

**설정 순서**
1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 토큰을 받습니다.
2. 만든 봇에게 아무 메시지나 보냅니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `chat.id` 숫자를 확인합니다.
4. `.env` 에 넣습니다. **키와 토큰은 채팅이나 다른 곳에 붙여넣지 마세요.**
   ```
   QUANT_TELEGRAM_TOKEN=...
   QUANT_TELEGRAM_CHAT_ID=...
   ```
5. 대시보드 **설정 → 휴대폰 · 외부 알림 → 테스트 전송** 을 누릅니다. "telegram ok" 가 나오면 연결된 것입니다.

**기본으로 보내는 알림**
- 보유 종목 ±5% 급등락
- 내가 만든 종목별 알림 규칙
- 실적 발표 D-1 · 당일
- 자동 정지(HALTED)
- 검증 사다리 승격·강등
- 아침 브리핑 · 일일 리포트 (예측 장부 봉인 해시 포함)

알림센터의 다른 종류도 텔레그램으로 받으려면 `.env` 에 `QUANT_NOTIFY_KINDS=rule,earnings,signal,disclosure` 처럼 적습니다 (기본: rule,earnings). 브리핑·리포트·보유 종목 급등락·자동 정지·강등은 이 설정과 상관없이 항상 보냅니다.

## 2. 앱으로 설치 + 웹 푸시

사이트를 닫아도 휴대폰 알림창에 뜹니다. 다만 휴대폰이 대시보드를 **HTTPS 주소**로 열 수 있어야 합니다.

**PC 에서만 쓸 때**
- `http://127.0.0.1:8050` 은 PC 브라우저에서 바로 설치와 푸시가 됩니다.
- **설정 → 앱으로 설치 / 이 기기 구독** 을 누르면 됩니다.

**휴대폰에서 쓸 때 — 안전한 방법 두 가지**
- **Tailscale (추천)**
  1. PC 와 휴대폰에 Tailscale 을 설치하고 같은 계정으로 로그인합니다.
  2. PC 에서 `tailscale serve --https=443 http://127.0.0.1:8050` 를 실행합니다.
  3. 휴대폰에서 `https://<PC이름>.<tailnet>.ts.net` 으로 엽니다.
  - 인터넷에 공개되지 않고, 내 기기끼리만 연결됩니다.
- **Cloudflare Tunnel**
  1. `cloudflared tunnel --url http://127.0.0.1:8050` 을 실행하면 https 주소가 나옵니다.
  2. 이 방법은 인터넷에 공개됩니다. 반드시 `.env` 에 다음을 넣으세요.
     - `QUANT_WEB_TOKEN` (긴 임의 문자열)
     - `QUANT_WEB_ALLOWED_HOSTS=<그 주소의 호스트>`

**휴대폰에서 연 뒤**
- **Android Chrome**: 메뉴 → 앱 설치 → 설정 → **이 기기 구독**.
- **iPhone**: Safari 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열고 → 설정 → **이 기기 구독** (iOS 16.4 이상).

## 3. 모바일 화면

폭이 좁은 화면에서는 아래쪽에 탭이 생깁니다: **홈 · 관제실 · 검증 · 그래프 · AI**.

## 보안

- 대시보드는 기본적으로 이 컴퓨터(127.0.0.1)에서만 열립니다.
- 외부에서 열 때는 항상 `QUANT_WEB_TOKEN` 을 설정하세요.
- 웹 푸시 개인키(`artifacts/vapid.json`)는 이 컴퓨터에만 있습니다.
- 푸시 서비스(Google·Apple·Mozilla)는 암호화된 내용을 볼 수 없습니다.
