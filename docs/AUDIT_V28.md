# V28 전수 점검 — 정식 출시 전에 고칠 것 (사용자 · 개발자 · 목표 관점)

> 2026-10-05 · V27(0.27.0) 기준 · 실데이터 서버(164종목 · AI 판단 3,050건)와 데모 서버로 직접 사용해 보고, 코드를 읽고, 숫자를 재서 정리했다.

## 0. 먼저 솔직하게 — 목표와 현재 수준

### 0-1. 100만원 → 1억 (6~12개월)
| 기간 | 필요한 수익 (복리) |
|---|---|
| 6개월 | 매달 **+115%** (매달 두 배 이상) |
| 12개월 | 매달 **+47%** |

- 이 시스템의 검증된 코어 전략: 16년 백테스트 **연 +7.6%**, 샤프 0.54, 최대 낙폭 **-43%** (비용·세금 반영). 이 분포로 1년에 100배가 될 확률은 사실상 0 (약 29 표준편차 밖).
- 세계 최상위 운용사도 장기 연 20~40%가 한계다. 100배를 노리려면 레버리지·몰빵·급등주 매매밖에 없고, 그 길은 **원금 전부를 잃을 확률이 훨씬 높다**.
- 그래서 자동매매가 이 목표를 향해 위험을 키우게 만드는 것은 권하지 않는다.
- **대안 — 같은 100만원으로 "증명 프로젝트"**: 6~12개월 동안 AI가 **비용·세금 뒤에도 지수를 이기는지**를 고칠 수 없는(봉인된) 기록으로 증명한다.
  - 성공 기준 예: 실주문 300건 이상 · 코스피 대비 연 +5%p 이상 · 최대 낙폭 -15% 이내 · 예측력 검정(SPRT) 통과.
  - 이 기록이 플랫폼 출시의 가장 강한 근거이자 마케팅 자료가 된다. "1억 만들었다"보다 "1년 동안 매일 공개 기록으로 지수를 이겼다"가 투자자·규제기관·언론에 훨씬 설득력 있다.

### 0-3. 플랫폼 출시 — 법·인가 (반드시 먼저 확인)
- **본인 계좌를 본인이 자동매매**: 지금 구조로 가능.
- **다른 사람에게 종목 추천을 판매·공개**: 유사투자자문업 신고 대상.
- **다른 사람 계좌를 AI가 대신 사고팔기**: 투자일임업 등록이 필요하고, 사람 없이 알고리즘으로 하면 코스콤 로보어드바이저 테스트베드 통과가 필요하다.
- **토스증권처럼 직접 주문을 받기**: 증권사 인가(투자중개업). 현실적인 길은 증권사 API 제휴, 또는 마이데이터 사업자(계좌 조회).
- 쓰고 있는 데이터(KRX 시세 모음 · Yahoo · 네이버 크롤링 · 로고 출처)는 **상용 서비스에 쓸 수 없다** (`docs/DATA_LICENSES.md`). 출시 전에 정식 데이터 계약이 필요하다.
- 출시 전에 금융 전문 변호사 검토를 꼭 받을 것.

## A. 사용자 입장에서 마음에 안 드는 것

### A-1. AI 추천 — 가장 큰 문제 🔴
1. **추천이 없다.** 홈 'AI가 본 오늘의 종목' 6개가 전부 '관망 51~62%'다. 사용자는 "그래서 뭘 사라는 거지?"가 된다.
2. **AI 이름과 실제 근거가 다르다.** LLM 키가 없으면 '뉴스 AI', '경제·시장 AI'가 같은 계산(20일 모멘텀)을 서로 다른 이름으로 반복한다. 예: 삼성전자 근거 1 "뉴스 AI: 20일 모멘텀 상승", 근거 2 "경제·시장 AI: 20일 모멘텀 상승". **신뢰를 깎는 지점**이다.
3. **여러 정보를 한데 모은 종합 점수가 없다.** 뉴스·공시·커뮤니티·수급(외국인·기관)·실적 서프라이즈·매크로·차트를 하나의 점수로 합쳐 줄을 세우는 화면이 없다. 수집기는 대부분 있지만 판단에 제대로 들어가지 않는다.
4. **매도 신호 화면이 없다.** "지금 팔면 좋을 것 TOP" — 보유 종목 위험 신호(손절선 도달·실적 악화·수급 이탈·악재 공시)를 한곳에 모은 화면이 없다.

**고칠 방향**
- **신호 엔진 2.0**: 종목마다 신호 7~10개를 표준 점수(-3~+3)로 만든다. 각 신호는 '과거 같은 신호가 나왔을 때 5·20일 뒤 실제 수익'으로 가중치를 매긴다(근거 = 데이터).
  - 신호 후보: 실적 서프라이즈 · 공시 종류(유상증자·자사주·수주) · 외국인/기관 순매수 연속일 · 뉴스 감성 변화 · 커뮤니티 과열/공포 · 52주 신고가 돌파 · 거래대금 급증 · 업종 상대강도 · 매크로 국면.
- 화면 **"오늘의 매수 후보 TOP 5 / 매도·비중 축소 후보 TOP 5"** — 종목마다:
  - 종합 점수와 방향.
  - 어떤 신호가 몇 점인지 (막대).
  - 과거 비슷한 신호 n번 중 m번 상승 · 평균 수익.
  - 이 판단이 틀렸다고 볼 가격(손절선).
  - 신뢰 등급 — 검증 전이면 그대로 '검증 전'으로 표시.
- 근거가 없는 AI는 이름을 숨기거나 '정보 없음'으로 표시한다. **정직하게.**
- LLM은 '요약·설명'에만 쓰고, 방향 판단은 검증 가능한 수치 신호로 한다. LLM 판단 적중률은 지금처럼 따로 채점한다.

### A-2. 로고 🔴
- **164종목 중 141개(86%)가 첫 글자 아이콘**이다 (오프라인 기준 · 내장 23개). 잘 알려지지 않은 종목은 거의 모두 해당한다.
- 사용자 PC 에서는 토스·알파스퀘어·네이버 등에서 일부 채워지지만, **비공식 출처라 출시용으로는 쓰면 안 된다.**
- 고칠 방향:
  - ① 정식 로고 API 계약 (logo.dev 등 유료 플랜 · 국내 커버리지 확인).
  - ② KRX 상장사 약 2,700곳 로고를 권리를 확인해 자체 CDN 에 구축 (기업 IR 페이지 · CI 다운로드 페이지 기준).
  - ③ 운영자 화면: '로고 없는 종목' 큐 → 한 번에 올리기 (V27 업로드 기능을 운영자용으로 확장).
  - ④ 첫 글자 아이콘도 업종 색 + 회사명 두 글자로 덜 허전하게.

### A-3. 주가 · 그래프가 허접해 보임 🔴
종목 화면에서 실제로 보이는 문제:
- 가격 축에 콤마가 없음 (`360000` → `360,000`).
- 마지막 가격 라벨(285500)이 눈금 글자(280000)와 겹침.
- 거래량 막대 위에 차트 라이브러리 로고(TV)가 붙어 있음 (출처 표기는 다른 방식으로 해야 함).
- 기본 차트가 '종가 선 하나'뿐: 캔들·이동평균·구간 드래그 수익률·실적/배당/AI 판단 변화 표시는 다른 탭에 있거나 없음.
- 실시간이 아님: 일봉 5거래일 밀림 (2026-09-23), 분봉은 Yahoo 비공식·지연. 실시간 틱은 KIS 키가 있어야 나옴.
- 시가총액 '-' (종목 상세 자료 미수집).
- **데이터 정합성 의심**: 삼성전자 52주 범위 72,100~374,500원, 1년 +273%. 수정주가·액면분할 처리 오류일 수 있다. 실제 시세와 반드시 대조할 것 (이 환경은 인터넷이 없어 대조 못 함).

토스 수준으로 가는 차트 사양:
1. 가격 축 콤마와 원/달러 단위 · 겹치지 않는 라벨 · 장중 실시간 점 깜빡임 · 전일 종가 점선.
2. 기간 1일(1분)·1주(10분)·1개월·3개월·1년·5년, 기간 등락을 크게.
3. 손가락으로 두 지점을 끌면 구간 수익률 표시.
4. 실적·배당·공시·AI 판단 변화를 마커로, 누르면 그날 무슨 일이 있었는지.
5. 캔들/선 전환, 이동평균 2~3개, 거래량 색.
6. 비교: 지수·업종 평균을 점선으로 겹쳐 보기.
7. 데이터 원천: 실시간 시세 계약(증권사 · 코스콤).

### A-4. 지수 · 데이터가 진짜 같지 않음 🟠
- 코스피가 '318.49 (대용)'으로 나온다. 진짜 코스피와 숫자가 달라 첫 화면부터 신뢰가 떨어진다 (V27에서 진짜 지수 수집을 넣었지만 인터넷 필요).
- 나스닥 · S&P500 칸이 '자료 없음'.
- 위 막대의 '데이터 5거래일 밀림', '점검 필요 3', 시계 두 개가 일반 사용자에게 겁을 준다. 내부 상태는 운영자 화면으로 옮길 것.

### A-5. 투자 전에 회사를 쉽게 알기 (출시 핵심 가치) 🟠
지금 종목 화면은 가격·AI 중심이고, **"이 회사가 뭐 하는 회사인지"가 약하다.** 필요한 것:
- 한 줄 소개 · 무엇으로 돈 버나 (매출 구성 도넛) · 주요 제품 · 경쟁사 3곳 비교.
- 재무 5년 막대 (매출 · 영업이익 · 순이익 · 부채비율) — DART 재무제표 API 미연결.
- 밸류에이션 (PER · PBR · 배당수익률) 동종 업종 비교 · 배당 이력.
- 주주 구성 (대주주 · 외국인 비율 추이).
- 최근 이슈 타임라인 (공시 · 뉴스 · 실적을 날짜순으로 한 줄씩).
- "초보자 3줄 요약": 좋은 점 · 걱정할 점 · 앞으로 볼 일정.

### A-6. 속도 🟡
- 처음 여는 화면의 서버 계산: AI 신뢰 센터 2.1초 · 홈 보조 칸 1.9초 · 사실 확인 1.6초 · 대시보드 1.3초 · 감시실 1.1초 (두 번째부터는 0.01초 미만).
- 화면 스윕에서 1.6초 안에 안 뜬 화면이 여러 개 있었다. 출시 수준은 0.3초 안에 첫 그림.
- 무거운 계산은 서버가 미리 계산해 두고, 화면은 저장된 결과만 읽게 바꿀 것.

### A-7. 너무 많고 어렵다 🟡
- 메뉴 56개 · 전문가 화면과 토스 화면이 이중으로 있다.
- 출시판에는 **사용자용 10개 안팎**(홈 · 검색 · 종목 · 관심 · 내 자산 · AI 추천 · 뉴스 · 알림 · 설정 · 학습)만 남기고, 나머지(검증 · 감시 · 운영 · 규제)는 **운영자 콘솔**로 분리.
- 내부 용어(그림자 장부, 사다리, 봉인, 드리프트)가 사용자 화면에 남아 있다.

### A-8. 가입 · 계좌 연결 · 주문 🟠
- 회원가입·소셜 로그인·비밀번호 찾기가 없다 (지금은 1인용 비밀번호).
- 증권 계좌 연결을 하려면 사용자가 KIS 키를 `.env` 에 직접 넣어야 한다 — 일반인은 할 수 없다. → OAuth 방식 증권사 연동 또는 제휴.
- 실주문은 KIS 국내만, 해외 실주문 없음. 지금 데이터가 오래돼서 모의 주문도 '차단'이 뜬다 (안전장치가 맞게 동작하는 것이지만, 이유를 더 친절하게).
- 앱스토어 앱이 없다 (PWA만). 알림은 웹 푸시와 텔레그램뿐 → 네이티브 앱 푸시.

### A-9. 뉴스 · 커뮤니티 🟡
- 번역·요약은 LLM이 있어야 제대로 된다 (V27 로컬 LLM으로 무료 대안은 생김).
- 커뮤니티는 네이버 크롤링이라 깨지기 쉽고 상용 불가.
- 뉴스는 RSS·구글뉴스 검색 → 정식 뉴스 API (연합 · 뉴스와이어 · 해외 Benzinga 등) 계약이 필요하다.

## C. 우선순위 로드맵 (제안)

### 1단계 (2~4주) — "증명 프로젝트" 준비 · 지금 바로
1. 데이터 정합성: 실제 시세와 대조 (수정주가 · 52주 · 시가총액) · 일봉 자동 갱신 확인.
2. **신호 엔진 2.0 + 매수/매도 후보 TOP 5 화면** (A-1).
3. KIS 모의투자로 주문 → 체결 → 장부 전 과정 검증 (`kis-check --suite`).
4. 100만원 실계좌 규칙: 종목당 상한 · 하루 손실 한도 · 정지 조건 · 매일 성과 공개 페이지 (봉인 기록).
5. 차트 기본 손질 (콤마 · 라벨 겹침 · 출처 표기 · 전일 종가선 · 구간 수익률).

### 2단계 (1~3개월) — 사용자 품질
6. 회사 이해 화면 (A-5) + DART 재무.
7. 로고 정식 원천 (A-2).
8. 사용자 화면 10개로 정리 + 운영자 콘솔 분리 (A-7).
9. 첫 화면 0.3초 (미리 계산).

### 3단계 (3~6개월, 증명 결과가 좋을 때) — 출시 준비
10. 백엔드/프론트 재구성 (B-1 · B-2 · B-3 · B-7).
11. 정식 데이터 계약 · 법률 검토 · 인가 경로 결정 (0-3).
12. 회원 · 증권사 연동 · 앱 · 보안 인증 (A-8 · B-8).

> 원칙: **AI가 기준선(지수·늘 오른다)을 이긴다는 봉인된 증거가 쌓이기 전에는 실제 돈을 늘리지 않는다.** 이 원칙이 결국 플랫폼의 신뢰가 된다.
